## How to Run the Projects

### Prerequisites
- Java Development Kit (JDK) installed
- Git installed

### Steps

1. Clone the repository:
```bash
git clone https://github.com/pornadey08-ai/Dey_Porna_object_oriented_programming_tutorials01.git
```

2. Navigate to a specific week's folder:
```bash
cd Dey_Porna_object_oriented_programming_tutorials01/week_10
```

3. Compile the Java files:
```bash
javac *.java
```

4. Run the main class:
```bash
java QuizBattleGUI
```
